# WatermarkRemover — retirer les filigranes des vidéos

Projet dans `D:\WatermarkRemover`, dépôt GitHub `Raphi52/WatermarkRemover`. Application de bureau **Python** qui **retire les filigranes (watermarks) des vidéos** par inpainting IA avec **ProPainter**, interface « glassmorphism ».

Points d'entrée : `main.py` (application), `install.bat` (installation), `download_model.py` (téléchargement du modèle). Consignes pour l'IA dans `CLAUDE.md`. Les résultats vont dans `output/`.
